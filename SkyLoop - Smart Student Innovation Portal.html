About SkyLoop

Project Overview

SkyLoop is a student-friendly educational portal combining news, experiments, and feedback into one smart platform. It is designed to demonstrate a practical and realistic final year project.

What Is SkyLoop?

Student-Centered Digital Platform

SkyLoop is built to help students stay informed, learn through simple simulations, and share opinions using one integrated browser-based system. It is designed using only HTML, CSS, JavaScript, and localStorage.

Objectives

Project Goals

Improve Student Awareness

Provide educational, technical, and campus-related updates in one place.

Improve Practical Learning

Use easy experiments to support academic understanding during demo and learning.

Collect Student Feedback

Allow users to submit ratings and suggestions for continuous improvement.

Build Smart Campus Tools

Show how digital student services can be organized in one responsive platform.
