# Paid Pilot Scope

## Recommended format

Duration: 4–6 weeks  
Customer: one team, one sponsor, one decision problem  
Deployment: one private workspace or controlled pilot environment  
Output: evidence-linked visual predictive experience plus ROI report

## Pilot objective

Turn one customer-selected scientific or technology question into an inspectable model with:

- source-linked evidence;
- entities, variables, dependencies, and causal assumptions;
- two or three conditional scenarios;
- an interactive visual model;
- risks, unknowns, and falsifiers;
- a decision summary written for the agreed audience.

## Example pilot

**Climate and Energy Intelligence Lab**

The customer selects a question such as how a technology, policy, or energy constraint could affect a defined system. SciLoop maps evidence and variables, allows controlled interventions, renders the resulting changes, and records what was assumed versus what was observed.

## Work plan

### Week 1 — Discovery and baseline

- Confirm the decision question and users.
- Define the baseline workflow and current time/cost.
- Agree approved sources and data boundaries.
- Define success metrics and unacceptable claims.

### Week 2 — Evidence and model

- Build the evidence brief.
- Create the knowledge graph and causal variable map.
- Identify assumptions, dependencies, unknowns, and falsifiers.

### Week 3 — Scenario and visual prototype

- Generate conditional scenarios.
- Compile a validated visual recipe.
- Connect a safe local/browser simulation where appropriate.

### Week 4 — User testing

- Run structured sessions with the pilot team.
- Measure comprehension, task time, and confidence separately.
- Record corrections and failure cases.

### Weeks 5–6 — Refinement and ROI report

- Improve the model and visual explanation.
- Compare baseline versus pilot measures.
- Deliver limitations, evidence coverage, and next-step recommendation.

## In scope

- One domain and one decision problem.
- One private pilot workspace.
- One evidence-linked predictive experience.
- Limited approved data ingestion.
- Human review before customer-facing publication.
- Exportable report and structured run record.

## Out of scope unless separately contracted

- Guaranteed forecasts.
- Fully autonomous decisions.
- Production-critical control systems.
- Broad enterprise data migration.
- Unreviewed AI-generated claims.
- Custom foundation-model training.
- Multi-region compliance commitments not yet implemented.

## Acceptance gate

The pilot is complete when the agreed users can reproduce the model, inspect its evidence and assumptions, run the visual scenario, understand its limitations, and review the measured pilot results.
