# Enterprise FAQ

## Is SciLoop a forecasting system?

No. SciLoop produces evidence-linked conditional scenarios and visual decision support. It does not guarantee future outcomes.

## What does AI do?

AI may prepare evidence, draft explanations, propose scenarios, or map a visual recipe. Outputs are untrusted drafts until they pass normalization, validation, guardrails, and human review.

## Can customers use their own data?

Only within an agreed pilot or deployment boundary. Data sources, retention, access, deletion, and provider handling must be reviewed before ingestion.

## Is customer data isolated?

Enterprise tenant isolation is a required implementation gate. The current repository is not yet a completed enterprise multi-tenant deployment.

## Can SciLoop integrate with existing systems?

The intended integration surface is a structured API for evidence briefs, scenario sets, visual specifications, run traces, and evaluation metadata. Integration scope must be defined per customer.

## Can the visual output be embedded?

Yes, as a future API or white-label capability, subject to deployment, identity, security, and licensing requirements.

## How do you measure success?

We agree on a baseline before the pilot. Measurements may include synthesis time, evidence coverage, comprehension, transfer, reuse, and prediction error where an outcome is observable.

## What happens when the model is uncertain?

Uncertainty, unknowns, risks, assumptions, and falsifiers are displayed as first-class output rather than hidden behind a single score.

## Is AGI OS included in the customer product?

No. AGI OS remains a research and evaluation surface. SciLoop receives only approved, versioned engine packages through an adapter boundary.

## What is available today?

The repository contains a working Next.js/React/TypeScript product, typed visual recipes, pattern and engine routing, evidence-linked possibilities, browser simulations, and early feedback/evolution modules. Enterprise identity, tenant storage, durable audit logs, and formal compliance controls still require implementation.
