# Enterprise Pricing Model

Pricing is a commercial hypothesis until validated through customer discovery. Do not publish these figures as commitments without confirming scope, support, hosting, data, and security requirements.

## Offer structure

| Offer | Purpose | Working price placeholder |
| --- | --- | ---: |
| Discovery workshop | Define one decision problem, baseline, sources, and success metrics. | INR 50,000–150,000 or USD 600–1,800 |
| Paid pilot | 4–6 week private Visual Predictive Engine pilot. | INR 3,00,000–10,00,000 or USD 3,600–12,000 |
| Team plan | Shared workspace, approved sources, standard support, usage limits. | INR 10,00,000–30,00,000/year or USD 12,000–36,000/year |
| Enterprise deployment | Custom identity, tenant controls, support, integrations, and governance. | Custom quote after requirements |
| API / white-label | Structured outputs and embedding rights under agreed usage and support. | Usage plus platform fee; discovery required |

## Pricing variables

- Number of users and workspaces.
- Data sources and ingestion volume.
- Scenario or run volume.
- Private hosting and retention requirements.
- SSO, audit, support, and integration requirements.
- Customer-facing or internal-only usage.
- Custom visual models and domain onboarding.

## Commercial rules

- Sell the pilot as a paid learning and proof engagement.
- Avoid unlimited usage promises.
- Separate implementation from recurring access.
- Record assumptions behind every quote.
- Never discount below the cost of evidence collection, engineering, support, and review.
