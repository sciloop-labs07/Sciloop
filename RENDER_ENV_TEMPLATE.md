# Render Environment Template

Use this as a copy sheet while filling Render variables.

## Frontend service

```text
SCILOOP_AI_BACKEND_URL=https://YOUR-AI-BACKEND.onrender.com
FORLOOP_BACKEND_URL=https://YOUR-FORLOOP-API.onrender.com
NEXT_PUBLIC_SCILOOP_AI_API_BASE=/api/sciloop-ai-proxy
NEXT_PUBLIC_SITE_URL=https://YOUR-FRONTEND.onrender.com
OPENAI_STREAM_MODEL=gpt-5
OPENAI_API_KEY=OPTIONAL_IF_YOU_USE_STREAMING
```
